# 산악회 버스 예약 시스템

여러 산악회의 연간 산행 계획을 등록하고, 버스 좌석(1~2열 제외)을 지정해 신청하면 가배정(노랑), 담당자가 입금을 확인하면 확정(빨강)되는 웹앱입니다.

## 설정 순서

1. **Supabase 프로젝트 만들기** → SQL Editor에 `schema.sql` 전체를 붙여넣고 실행 (처음 설정할 때 한 번만 실행하세요. 다시 실행하면 기존 데이터가 삭제됩니다)
2. **총괄 관리자 계정**: Authentication > Users에서 계정을 만들고, SQL Editor에서 아래를 실행
   `insert into super_admins (user_id) select id from auth.users where email = '내이메일@example.com';`
3. **담당자 계정**: 산악회 담당자마다 Authentication > Users에서 계정을 만들어 둡니다. (신규 가입 허용은 꺼두세요)
4. `index.html` 위쪽의 `SUPABASE_URL`, `SUPABASE_ANON_KEY`를 Project Settings > API 값으로 교체
5. 앱에서 **관리자 > 총괄 로그인** 후 산악회 추가 → 담당자 이메일 지정

## 연간 산행 계획 일괄 등록

관리자 화면의 "연간 계획 한꺼번에 등록"에 한 줄에 `산악회, 산행명, 날짜, 정회원 회비, 일일회원 회비`로 붙여넣습니다. (회비는 생략 가능) (엑셀 복사 또는 CSV 파일 불러오기)

```
우리산악회, 북한산 백운대, 2026-11-08 07:00, 45000, 50000
우리산악회, 설악산 대청봉, 2026-12-13, 52000, 58000
```

## 규칙

- 산행을 등록하면 1호차(45인승)가 자동 생성되고, 담당자가 "버스 추가"로 호차를 늘릴 수 있습니다. (좌석 수 지정 가능)
- **정회원/일일회원 회비**는 산행마다 담당자가 등록·수정합니다. 신청자는 탑승자마다 회원 구분을 고르고, 구분별 회비를 합산한 금액이 안내되며 명단에도 기록됩니다.
- **입금 계좌**와 기한은 산악회별로 담당자가 "산악회 정보"에서 수정합니다.
- 산행의 이름·날짜·회비는 "수정" 버튼으로 고칠 수 있고, 연도별로 골라 볼 수 있습니다.
- 입금 기한은 산악회별로 설정(기본 48시간)하며, 지나면 가배정이 자동으로 풀립니다.
- 담당자는 자기 산악회의 산행과 예약자 명단만 볼 수 있습니다.
